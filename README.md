# Health Screening Telegram Bot (k-NN ML)

Telegram-бот для самостоятельного экспресс-скрининга здоровья и первичной оценки рисков хронических заболеваний. 
Разработан в рамках курсовой работы.

---

## 📌 Суть проекта

Telegram-бот, в котором человек может завести свою медицинскую карту и проверить базовые показатели здоровья. Пользователь указывает рост, вес, возраст и давление, а бот считает индекс массы тела (ИМТ) и суточную норму калорий.
После этого прямо в чате можно оценить риски болезней (диабет, проблемы с сердцем, сосуды) или пройти короткие тесты на уровень стресса и бессонницу. Бот анализирует ответы, выдает понятный результат с процентом риска и сохраняет всё в историю проверок.



## ⚙️ Реализация
Весь алгоритм машинного обучения (k-NN) будет написан с 0 на Python, без готовых библиотек вроде sklearn. Программа будет сравнивать показатели пользователя с данными с Kaggle: приводить числа к единому масштабу, считать расстояние между точками и по похожим случаям определять риск.
Все профили пользователей и история их чекапов будут сохраняться в базу данных SQLite. Сам бот будет работать через пошаговые вопросы с кнопками .

## ⛓️ Технологический стек

* Язык разработки: Python 3.11+
* Telegram Framework: aiogram 3.x
* База данных: SQLite3 (встроенный модуль)
* ML / Алгоритмы: Собственная реализация k-NN (модули math, csv)

## 📂 Структура проекта

```text
health_bot/
│
├── data/                  # Обучающие выборки в формате CSV
│   ├── diabetes.csv       # Pima Indians Diabetes Database (риск диабета)
│   ├── heart.csv          # Heart Disease UCI (риск сердечно-сосудистых патологий)
│   └── stroke.csv         # Stroke Prediction Dataset (оценка риска инсульта)
│
├── knn_core.py            # Математическое ядро классификатора:
│                          # - парсинг CSV-файлов вручную
│                          # - нормализация параметров
│                          # - расчет евклидова расстояния
│                          # - поиск k-соседей и прогноз (голосование)
│
├── formulas.py            # Медицинские калькуляторы:
│                          # - расчет индекса массы тела (ИМТ) и категории
│                          # - суточная норма калорий (формула Миффлина-Сан Жеора)
│                          # - интерпретация показателей артериального давления
│   
├── database.py            # Управление базой данных SQLite:
│                          # - создание таблиц 
│                          # - сохранение результатов скрининга
│                          # - выгрузка истории измерений для пользователя
│
├── bot.py                 # Логика работы Telegram-бота:
│                          # - FSM 
│                          # - клавиатуры и текстовые подсказки
│                          # - вывод рекомендаций и дисклеймеров
│
├── main.py                # Файл запуска бота
├── .gitignore             # Игнорирование системных файлов и БД
└── README.md              # Документация проекта
```
